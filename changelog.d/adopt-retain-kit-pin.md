## Choose the kit ref in the shell that runs adoption Step 0

Set `KIT_REF` to your chosen tag, branch or full commit SHA in the same invocation
as the kit block. To select the remote's default branch, explicitly set `KIT_REF=''`.
If setup stops with an `agentic-dev-kit.pending` directory, confirm the attempt
has ended and inspect that directory before removing it and retrying.
