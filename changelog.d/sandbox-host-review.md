## Trusted Claude reviews on the host

On macOS, configure `review.fallback_panel.host_sandbox.claude_version` and its system-tool `read_paths`, then repeat the documented live acceptance probes. Use `panel_prompt.py --launch --trusted-source` from an independent trusted installation for trusted Claude source. Supply `ANTHROPIC_API_KEY` for the model client and stage test dependencies in the allocated round. Use explicit temporary paths within that round.

Keep an absolute `worker_launcher` for external contributions and Codex reviews. A configured worker takes precedence. The host launcher refuses an unprobed Claude version.
