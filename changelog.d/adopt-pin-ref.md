## Pass a ref when you install or upgrade the kit; a lite U2 read of it takes `--expect-commit`

`adopt.md` and `upgrade.md` Step 0 now clone the kit at a ref you name: set `KIT_REF` to a release tag or a full commit sha before running the kit block, and the block prints the resolved commit (`kit commit: <sha>`) before the first copy. Put that sha in the adoption's or upgrade's pull request. With no `KIT_REF` the block uses `main`, as it stands when it runs. When the block finds a clone an earlier run made, it checks a named ref against the clone's `HEAD` without fetching into it, and with `main` its `kit commit:` line says the found clone was not re-checked.

`kit_doctor.py --upgrade-lite` takes a new read-only flag, `--expect-commit <sha>`: U2's read checks the kit clone is at that commit instead of at its origin's HEAD, and is otherwise unchanged. A lite upgrade that named a ref adds `--expect-commit <sha>`, the sha the kit block printed, to U2's command; U4 and U5 keep `--kit-commit` as before. The two flags are refused together, and `--expect-commit` is refused with `--apply` and outside `--upgrade-lite`. The `--json` plan's `kit` object gains an `expected` boolean. With no ref named, U2 runs as before. The flag is read by the named ref's own `kit_doctor.py`, so a lite upgrade can name only a ref at or after the commit that added it: an older one stops U2 with `kit_doctor.py: error: unrecognized arguments: --expect-commit <sha>`. Every `--upgrade-lite` mode now refuses (exit 1) a kit clone whose history holds the committed baseline's `kit_commit` but whose HEAD does not contain it, as a downgrade; under `--expect-commit` a baseline commit missing from the clone's history is refused too. In a full upgrade with a named ref, the changelog block stops with a `stop:` line, instead of taking the degraded path, when the baseline is in the clone's history but is not an ancestor of its HEAD, and it now requires `KIT_REF`, which the kit block sets. The kit block refuses a `KIT_REF` that starts with `-`, and lower-cases a full sha.
